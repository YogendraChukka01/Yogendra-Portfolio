# Yogendra Chukka — Next-Generation AI Engineer Portfolio

A modern, high-performance **AI Engineer Portfolio** built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **React Three Fiber (Three.js)**, and **Lucide Icons**.

## Features

- **Interactive 3D Node Graph** — React Three Fiber AI orchestration visualization representing models, RAG, agents, and tool execution with full static fallback.
- **14-Node AdaptiveAgent Pipeline** — Interactive execution flow simulator showing LangGraph states, confidence scoring, and risk assessment.
- **Chief-AI Multi-Agent Department Map** — Interactive 11-department software organization architecture showcasing 55 specialist sub-agents.
- **Command Palette (`⌘K` / `Ctrl+K`)** — Keyboard-driven modal for instant navigation, case study jumping, social links, and theme switching.
- **Verified GitHub Intelligence** — Strictly verified engineering metrics sourced directly from public repository inspections.
- **Deep Case Study Routes** — Dynamic routes (`/work/adaptive-agent`, `/work/chief-ai`, etc.) built with static export support.
- **Light/Dark Mode** — Clean neutral editorial visual system powered by `next-themes`.

## Tech Stack

- **Framework:** Next.js 15 (App Router, Static Export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **3D Visualization:** React Three Fiber / Three.js
- **Icons:** Lucide React
- **Theme Management:** `next-themes`

## Verification & Build

```bash
npm run build
```

Exports static output directly into the `out/` directory ready for deployment on Vercel, GitHub Pages, Netlify, or Render.
